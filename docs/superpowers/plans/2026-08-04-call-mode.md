# Call Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a second, independent recording mode — Call Mode — that captures both sides of a call (mic + system audio via an Aggregate Device), streams chunked transcription for the call's full length, and on stop delivers the transcript to a file + clipboard (never auto-paste) plus a "Calls" history menu.

**Architecture:** Reuse the existing `Recorder`/chunk-streaming/transcriber pipeline almost unchanged — `Recorder` gains an optional `device`/`all_channels` pair so it can point at an Aggregate Device instead of the default mic, and its existing multi-channel-to-mono downmix does the "merge mic + system audio" work for free. A parallel `call_session`/`call_state` pair of dicts, a `CallToggle` gesture, and a `"mode": "call"` tag on jobs let the single existing `control_loop`/`worker` pair (one PortAudio thread, one transcription queue) drive both dictation and calls without duplicating that machinery. A new `calls.py` module (mirrors `history.py`) owns the transcript file + metadata list.

**Tech Stack:** Python 3, stdlib (`json`/`os`/`time`/`tempfile`/`re`), `sounddevice`/`numpy` (already a dependency via `Recorder`), `rumps` (menu), `pynput` (hotkeys), `unittest`.

```python
"""Persistent call-recording transcripts for Just Voice Type.

Two things live here: the transcript **files** (one per call, under
~/Documents/JustVoiceType/Calls/ — visible and Finder-browsable, unlike the
dotfile config dir, since this is what the user goes and grabs manually) and
a lightweight **metadata list** (~/.config/just-voice-type/calls.json,
honors $XDG_CONFIG_HOME via the config module) holding {ts, duration_sec,
path, preview} — never the full text, so it stays small regardless of call
length. Pure I/O + formatting helpers, no GUI deps — unit-testable.
"""
from __future__ import annotations

import json
import os
import sys
import tempfile
import time
from typing import Any, Optional

import config

CALLS_SUBDIR = "Calls"
CALLS_FILE_NAME = "calls.json"
MAX_ITEMS = 30
MENU_ITEMS = 10
LABEL_LEN = 60


def calls_dir() -> str:
    base = os.path.expanduser("~/Documents")
    return os.path.join(base, "JustVoiceType", CALLS_SUBDIR)


def calls_meta_path() -> str:
    return os.path.join(config.config_dir(), CALLS_FILE_NAME)


def transcript_path(ts: float) -> str:
    """Файл транскрипта для звонка с меткой времени `ts`; при коллизии имени
    (два звонка в одну и ту же минуту) добавляет -2, -3, … суффикс."""
    d = calls_dir()
    stamp = time.strftime("call-%Y-%m-%d_%H-%M", time.localtime(ts))
    base = os.path.join(d, f"{stamp}.txt")
    if not os.path.exists(base):
        return base
    n = 2
    while True:
        candidate = os.path.join(d, f"{stamp}-{n}.txt")
        if not os.path.exists(candidate):
            return candidate
        n += 1


def start_transcript(ts: float) -> str:
    """Создать пустой файл транскрипта звонка на диске; вернуть его путь."""
    os.makedirs(calls_dir(), exist_ok=True)
    path = transcript_path(ts)
    with open(path, "w", encoding="utf-8"):
        pass
    return path


def append_chunk(path: str, text: str) -> None:
    """Дописать один распознанный кусок в файл транскрипта — устойчивость
    к падению приложения посреди долгого звонка: на диске всегда лежит
    «всё расшифрованное на данный момент», а не только финальный текст."""
    if not text or not text.strip():
        return
    try:
        with open(path, "a", encoding="utf-8") as f:
            f.write(text.strip() + " ")
    except OSError as e:
        print(f"[!] call transcript append failed: {e}", file=sys.stderr)


def finalize(path: str, full_text: str) -> None:
    """Перезаписать файл транскрипта финальным (склеенным) текстом — куски
    на диске могли разрезать слово криво на границе чанка."""
    with open(path, "w", encoding="utf-8") as f:
        f.write(full_text)


def load() -> "list[dict[str, Any]]":
    try:
        with open(calls_meta_path(), "r", encoding="utf-8") as f:
            raw = json.load(f)
    except FileNotFoundError:
        return []
    except (json.JSONDecodeError, OSError) as e:
        print(f"[!] calls load failed ({e}); starting empty", file=sys.stderr)
        return []
    if not isinstance(raw, list):
        return []
    items = []
    for it in raw:
        if not isinstance(it, dict):
            continue
        path = it.get("path")
        preview = it.get("preview")
        if not isinstance(path, str) or not path or not isinstance(preview, str):
            continue
        try:
            ts = float(it.get("ts") or 0.0)
        except (TypeError, ValueError):
            ts = 0.0
        try:
            duration_sec = float(it.get("duration_sec") or 0.0)
        except (TypeError, ValueError):
            duration_sec = 0.0
        items.append(
            {"ts": ts, "duration_sec": duration_sec, "path": path, "preview": preview}
        )
    return items[:MAX_ITEMS]


def save(items: "list[dict[str, Any]]") -> None:
    d = config.config_dir()
    try:
        os.makedirs(d, exist_ok=True)
        fd, tmp = tempfile.mkstemp(dir=d, prefix=".calls-", suffix=".tmp")
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            json.dump(items[:MAX_ITEMS], f, ensure_ascii=False, indent=2)
        os.replace(tmp, calls_meta_path())
    except OSError as e:
        print(f"[!] calls save failed: {e}", file=sys.stderr)


def add(
    path: str, full_text: str, duration_sec: float, now: "Optional[float]" = None
) -> "list[dict[str, Any]]":
    """Добавить звонок в начало списка метаданных; вернуть обновлённый список."""
    text = " ".join((full_text or "").split())
    if not text:
        return load()
    preview = text if len(text) <= LABEL_LEN else text[: LABEL_LEN - 1] + "…"
    items = load()
    items.insert(
        0,
        {
            "ts": now if now is not None else time.time(),
            "duration_sec": duration_sec,
            "path": path,
            "preview": preview,
        },
    )
    items = items[:MAX_ITEMS]
    save(items)
    return items


def clear() -> None:
    save([])


def label(index: int, item: "dict[str, Any]", max_len: int = LABEL_LEN) -> str:
    """Подпись пункта меню: номер + время + длительность + усечённое превью."""
    preview = item.get("preview", "")
    if len(preview) > max_len:
        preview = preview[: max_len - 1] + "…"
    ts = item.get("ts") or 0
    when = time.strftime("%H:%M", time.localtime(ts)) if ts else "--:--"
    dur = int(item.get("duration_sec") or 0)
    mins = dur // 60
    return f"{index}.  {when} ({mins} мин)  {preview}"
```

```python
class CallToggle:
    """Простой toggle для отдельного хоткея Call Mode: нажал — начинается
    запись звонка, нажал ещё раз — заканчивается. В отличие от
    GestureRecognizer, никакого различия hold/double-tap/tap — только защита
    от автоповтора ОС, пока клавиша физически удерживается.
    """

    def __init__(self):
        self.active = False
        self._key_down = False

    def on_press(self, now: float) -> "Optional[str]":
        if self._key_down:
            return None  # автоповтор ОС, клавиша ещё держится — игнор
        self._key_down = True
        self.active = not self.active
        return "call_start" if self.active else "call_stop"

    def on_release(self, now: float) -> None:
        self._key_down = False
```

```
## Call Mode

A second, independent recording mode for calls (Teams, WhatsApp, Zoom, anything). Unlike dictation, Call Mode:

- Records **both sides** — your microphone and the call's system audio — merged into one stream.
- Runs for as long as the call lasts (up to a 4-hour safety cap), transcribing in the background the same way long dictations do.
- On stop, saves the full transcript to `~/Documents/JustVoiceType/Calls/` **and** copies it to the clipboard — paste it into any AI tool for analysis. No auto-paste into a field.
- Starts/stops via the **Call → Start/Stop Call Recording** menu item, or a dedicated toggle hotkey (**Call Hotkey** menu, default `F13`) — independent of the dictation hotkey. Starting one mode blocks the other.
- Past calls are listed under **Calls** — click one to copy its transcript back to the clipboard, or use **Open Calls folder…**.

Call Mode does **not** do speaker labels, a live growing transcript, or save the raw audio.

### One-time setup (per Mac)

Capturing the other side of a call requires a virtual audio loopback device — macOS has no built-in way to record its own output. This is a one-time setup, not something the app can do for you:

1. Install a virtual audio driver if you don't already have one — e.g. [VB-Cable](https://vb-audio.com/Cable/) or [BlackHole](https://github.com/ExistentialAudio/BlackHole) (free).
2. Open **Audio MIDI Setup** (Spotlight → "Audio MIDI Setup") and create an **Aggregate Device** combining your Mac's microphone and the virtual cable (e.g. "MacBook Pro Microphone" + "VB-Cable"). This becomes your input — select it in Just Voice Type's **Call Device** menu.
3. Create a **Multi-Output Device** combining your speakers/headphones and the same virtual cable, so you keep hearing the call while it's captured.
4. Route the call app's own audio output to that Multi-Output Device — preferred over changing the whole Mac's system output, since it only captures the call itself:
   - **Teams:** Settings → Devices → Speaker (or, mid-call, the ⋯ menu → Show Device Settings).
   - **WhatsApp Desktop:** the call screen has its own speaker-selection menu.
   - Apps without a per-app output picker: change **System Settings → Sound → Output** to the Multi-Output Device for the duration of the call, then switch it back afterward.
```
